## 2. План, який запропонував Codex

1. **Аналіз та аудит кодової бази**:
   - Виявлення залежностей від браузерних сховищ (`localStorage`, `Cookie`) та глобальних змінних.
   - Перевірка структури `data/data.json` та шарів `repositories/`, `services/`, `routes/`.
2. **Створення надійного Backend**:
   - Автоматичне створення каталогу `data/` та файлу `data.json`, якщо вони відсутні.
   - Захист від пошкодженого JSON (HTTP 500 без перезапису файлу).
   - Потокобезпечний запис за допомогою Promise Mutex черги (`runInQueue`).
   - Повна валідація сутності фільму (`utils/validation.js`).
   - REST API маршрути для всіх CRUD операцій: `GET`, `POST`, `PUT`, `PATCH`, `DELETE`.
   - Маршрут статистики `GET /api/movies/stats` (оголошений до `/:id`).
   - Інтеграція із зовнішнім TVMaze API з таймаутом і захистом від 502 помилок.
3. **Рефакторинг Frontend (`public/script.js`, `public/index.html`)**:
   - Переведення всіх операцій на асинхронні виклики `fetch()` до сервера.
   - Додавання індикації завантаження (`Loading...`).
   - Сповіщення про успішні операції та помилки сервера.
   - Блокування кнопок під час надсилання запитів для захисту від подвійних кліків.
   - Підтвердження перед видаленням.
4. **Реалізація нової комплексної функції**:
   - Персоналізована система рекомендацій (`GET /api/movies/recommendations`), яка обчислює улюблений жанр користувача та рекомендує нові серіали з TVMaze.
5. **Дизайн та тестування**:
   - Редизайн інтерфейсу в мінімалістичному стилі iOS.
   - Комплексне тестування крайових випадків та перевірка персистентності даних.

## 4. Що Codex зробив неправильно

1. **Неправильна логіка пошуку рекомендацій у TVMaze**:
   - Спочатку Codex робив запит до `https://api.tvmaze.com/search/shows?q=Action`. Це виконувало текстовий пошук за словом у назві, через що поверталися невідомі шоу з назвами на зразок *"Action"*, *"Action Team"*, *"Action Sports"* із нульовим рейтингом, замість популярних бойовиків.
2. **Помилка з поверненням раніше обраних фільмів**:
   - У першій версії рекомендацій система рекомендувала фільми, які вже були у списку користувача зі статусом `plan`.
3. **Падіння сервера при зайнятому порту**:
   - Спочатку `server.js` жорстко викликав `app.listen(3000)`. Коли на комп'ютері у фоні працював інший проєкт (Next.js), сервер падав із критичною помилкою `EADDRINUSE: address already in use :::3000`.

## 7. Яку нову функцію було додано

**Персоналізована інтелектуальна система рекомендацій (`GET /api/movies/recommendations`):**
- **Backend:**
  - Аналізує всі фільми користувача зі статусом `watched`.
  - Обчислює статистику частоти жанрів та визначає улюблений жанр.
  - Звертається до зовнішнього TVMaze API для пошуку топових шоу цього жанру.
  - Суворо фільтрує список: виключає будь-які фільми, які користувач уже переглянув або запланував до перегляду.
  - Сортує за рейтингом (від найвищого до найнижчого).
  - Має fallback-захист: якщо зовнішній API не відповідає, повертає збережені фільми зі статусом `plan` без падіння сервера.
- **Frontend:**
  - Окрема кнопка `✨ Отримати рекомендації`.
  - Індикація завантаження та рендеринг карток фільмів з можливістю додати рекомендований фільм у свій список в один клік.
